# Entre Costuras

Web para un taller de arreglos de ropa en Granada.

🔗 **Demo:** https://proyecto-entre-costuras.pages.dev/
📌 **Tipo:** Proyecto real · Negocio local

![Captura de Entre Costuras](img/Captura.webp)

## Qué incluye
- Presentación de servicios
- Diseño adaptable a móviles
- Vías de contacto para consultas de clientes  
- Whatsapp  
- Mapa


## Tecnologías
HTML5 · CSS3 · JavaScript (vanilla)


## Ejecutar en local
```bash
git clone https://github.com/edvillamizar/proyecto_entre_costuras.git
cd REPO
# abrir index.html con Live Server (VS Code)
```
